# AI Essay Reviewer

A web app that gives instant, structured feedback on any essay using the Claude AI API.

## Features

- Paste any essay and get feedback in seconds
- Scored out of 100 with an overall summary
- Feedback broken down into: Structure, Clarity & Style, Argument & Content, Grammar & Mechanics
- Top 3 actionable suggestions for improvement
- Supports any essay type: argumentative, personal statement, research paper, and more
- Dark mode UI

## Tech Stack

- HTML, CSS, JavaScript
- Anthropic Claude API (claude-haiku-4-5-20251001)

## How to Use

1. Clone the repo and open `index.html` with Live Server
2. Enter your Anthropic API key when prompted
3. Paste your essay and optionally specify the essay type
4. Click **Review My Essay**
